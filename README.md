# افیکسا — fxa.ir

استودیوی صدای هوشمند افیکسا — یک صفحه‌ی فرود (Landing Page) تک‌فایلی و راست‌چین.

## میزبانی با GitHub Pages
1. این مخزن را روی گیت‌هاب بسازید و فایل‌ها را آپلود کنید.
2. به **Settings → Pages** بروید.
3. در بخش **Source**، شاخه `main` و پوشه `/ (root)` را انتخاب و ذخیره کنید.
4. بعد از چند دقیقه سایت روی آدرس `https://<username>.github.io/<repo>/` بالا می‌آید.

برای دامنه‌ی اختصاصی `fxa.ir`: در همان صفحه‌ی Pages، در **Custom domain** مقدار `fxa.ir` را وارد کنید و در پنل DNS دامنه، رکوردهای لازم (A/CNAME) گیت‌هاب را تنظیم کنید.

تمام صفحه در فایل `index.html` است؛ فونت‌ها از Google Fonts بارگذاری می‌شوند.
