# قالب‌های ذخیره‌شده

## `afixa-studio-component.html`
قالب **استودیوی تعاملی** افیکسا — بخش «انتخاب ابزار + ورودی + تنظیمات + پردازش نمایشی + خروجی».

این بخش از صفحه‌ی اصلی سایت حذف شد (طبق بازخورد: تمرکز روی معرفی توانایی‌ها)، اما چون قالب و ظاهرش ارزشمند بود این‌جا جداگانه نگه داشته شد تا بعداً — حتی با کارکردی متفاوت — زیر همین ظاهر دوباره استفاده شود.

- کاملاً مستقل و تک‌فایلی (HTML + CSS + JS داخل خودش).
- راست‌چین، فارسی، با حالت روشن/تاریک.
- همان توکن‌های رنگ و تایپوگرافی سایت اصلی را دارد، پس به‌راحتی در ساختار سایت ادغام می‌شود.
- برای دیدن: فایل را در مرورگر باز کنید.
